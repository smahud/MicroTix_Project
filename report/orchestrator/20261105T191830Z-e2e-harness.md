## Dua bug NYATA ditemukan + diperbaiki (bukti nilai harness)

1. **FE: login non-MFA tidak pernah menavigasi** — `LoginPage.tsx` hanya
   menangani `requires_totp`; era mock hanya menguji jalur TOTP. Login live
   sukses 200 tapi halaman diam. Fix: `navigate('/app')` +
   `src/state/session.tsx` `login()` menyegarkan query sesi (paritas
   `loginTotp`: `removeQueries` predicate + `refetchQueries(['session'])`).
2. **CSRF lintas-origin topologi dev** — browser (Origin 5173) → proxy →
   backend 8010: Django 4+ menolak → 403 semua mutasi. Fix:
   `CSRF_TRUSTED_ORIGINS` khusus non-produksi (`127.0.0.1:5173`,
   `localhost:5173`); produksi same-origin (Caddy 443) — daftar tetap kosong,
   **tidak ada pelembutan produksi** (diverifikasi reviewer).

Tidak dieksekusi: alur yang butuh router nyata (enrollment fisik) — G1 BLOCKED;
CI e2e job di GitHub Actions (lanjutan opsional — caching browser + stabilitas).

## Keamanan & kompatibilitas

- Spec hanya berinteraksi via UI + API nyata; tidak ada endpoint/mock baru; token dibaca lewat jalur email dev (log konsol) — bukan bypass.
- `page.request` (bawa cookie sesi browser) dipakai untuk probe isolasi — probe unauthenticated dengan fixture `request` terbukti menghasilkan asersi palsu (403 ≠ 404) dan DIPERBAIKI.
- Produksi tidak terpengaruh (hanya devDeps + dev topology).
