## Keputusan engineering (dengan justifikasi)

1. **Renderer PDF = xhtml2pdf 0.2.28** (bukan WeasyPrint): ARCHITECTURE.md §1
   mensyaratkan HTML→PDF dengan renderer terbatas jaringan/file. xhtml2pdf
   murni Python+wheels (tanpa pango/cairo/dependensi sistem) → tidak menambah
   permukaan sistem pada host produksi/sandbox/CI; reportlab
   `rl_config.invariant=1` memberi PDF byte-deterministik (terbukti tes);
   sumber daya dibatasi dua lapis (ResourceAccessPolicy allow_remote=False +
   guard regex src/href eksternal → 422). Solusi terkecil yang compliant
   (CONTRACT §3); tidak ada infrastruktur/cache/layanan baru.
2. **Dokumen = snapshot immutable; reprint = baca artifact + cek sha256**
   (I18N-01 §2): template/locale baru tidak pernah mengubah dokumen terbit
   (T23-I18-02-A01 teruji). Artifact ditulis SEBELUM row (rollback DB
   menyisakan paling buruk file yatim — tidak pernah row tanpa artifact).
3. **Invoice/pembayaran tidak memposting ledger M7** — sesuai urutan
   topologis (TK-701 depends_on TK-601 build; posting rules FINANCE §3
   menyusul di M7). Slice ini catatan sumber (mirip event sumber platform M2).
4. **Nomor dokumen via kunci baris tenant** (SELECT FOR UPDATE tenancy_tenant)
   → penomoran INV-/RCP- terserialisasi per tenant; UNIQUE DB tetap
   menjaga (409 saat balapan).
5. **Total invoice negatif ditolak jujur** (billing.invalid_total) — diskon
   melebihi nilai = salah konfigurasi, bukan dipotong diam-diam.
6. **free_until_next_period → invoice total 0 state paid** — periode tetap
   tercatat; tidak ada tagihan terutang fiktif.
7. **Anniversary + first_period_policy≠full ditolak** (BIL-02) — tanpa field
   "batas kalender pertama eksplisit" dalam kontrak, menolak lebih aman
   daripada menerka.
8. **Pembayaran tidak menyentuh lifecycle service** (PRODUCT §13): aktivasi
   manual terpisah (TK-604 UI). Teruji eksplisit.
9. **`external_ref` opsional-unik per tenant** — replay event bank sama → 409
   (dedup); dua transfer nyata = dua Payment (TK-203 semantik).
10. **FK PROTECT** pada invoice→service & allocation→payment/invoice: bukti
    keuangan tidak ikut terhapus (retensi FINANCE §16).
11. **Fix Makefile PY/MANAGE absolut** — bug pra-ada (path relatif rusak
    setelah `cd backend`; `make test*` tidak dapat menjalankan venv). CI tak
    terdampak (CI `python -m pytest` langsung); target standar §4 kini benar.
12. **Tenant.locale/Customer.locale** — rantai bahasa dokumen I18N-01 §2
    (diperlukan BIL-01 "dokumen memuat bahasa terbit"); UI pengaturan bahasa
    menyusul (I18N-06) — field ada, default aman (id).

## Keamanan & kompatibilitas

- RLS FORCE + policy tenant_isolation semua tabel baru (billing 6 + documents
  1); 404 generik lintas tenant teruji (API + ORM scope).
- Trigger immutability DB (documents) — berlaku melewati privilese aplikasi.
- Renderer tanpa fetch jaringan/berkas (dua lapis, teruji); nilai di-escape
  (anti injeksi HTML ke PDF teruji); filename download disanitasi (header
  injection); bukti pembayaran via pipeline magic-bytes TK-106 (MIME dari
  isi, bukan klaim; klaim MIME di-allow-list).
- Tidak ada rahasia/kredensial dalam commit (PAT hanya di `.git/config`
  lokal); values dokumen tidak di-log.
- Migrasi hanya ADDITIVE (AddField + tabel baru) — tidak ada perubahan
  kolom/lookup eksisting; upgrade-safe; dependensi lintas-app dicek graph.
- `CheckConstraint` negara uang (amount>0, allocated≤amount, total≥0)
  ditegak DB, bukan hanya serializer.
