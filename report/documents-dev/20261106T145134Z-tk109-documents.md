## Keputusan engineering (dengan justifikasi)

1. **Determinisme reprint** — `rl_config.invariant = 1` pada import modul
   render: metadata tanggal PDF tetap; dua render HTML sama menghasilkan byte
   identik (terverifikasi tes unit: sha256 sama). Ini membuat "reprint
   konsisten" dapat diaudit lewat sha256 tanpa menyimpan byte asli.
2. **Artifact-sebelum-row** — file PDF ditulis dulu (0600, fsync), row DB
   sesudahnya: rollback transaksi paling buruk menyisakan file yatim, tidak
   pernah row yang menggantung tanpa artifact. Tambahan kecil: pada
   IntegrityError duplikat, artifact baru dihapus best-effort (tidak
   menambah akumulasi file yatim pada kasus paling umum).
3. **Renderer benar-benar dibatasi (defense-in-depth 2 lapis)** — lapis 1:
   `assert_no_external_refs` (regex, seperti spesifikasi); lapis 2:
   `ResourceAccessPolicy(allow_remote=False, base_dir=None)` dari xhtml2pdf
   0.2.28 menutup SEMUA jalur fetch (termasuk `@font-face`, `url()` CSS,
   `<pdf:*>` yang tidak tercakup regex). Ini implementasi langsung baris
   ARCHITECTURE §1 "Dokumen", parameter bawaan library terpasang — tanpa
   dependensi/abstraksi baru.
4. **401 jujur untuk anonim** — `permission_classes=[]` + `TenantPermission`:
   kombinasi default DRF (`IsAuthenticated` + SessionAuthentication tanpa
   WWW-Authenticate) memaksa anonim jadi 403, padahal kontrak §5 minta 401.
   `resolve_membership` sudah menuntun 401/404/403 dengan benar; preseden
   sama didokumentasikan pada `PlatformApiView` (subscriptions/views.py).
5. **Uang tidak pernah float** — `format_idr` menerima str/Decimal, seluruh
   aritmetika `decimal.Decimal`; suffix sen hanya bila != 0 (I18N-03).
6. **Anti-API-palsu** — kind tanpa templat terdaftar (saas_invoice/report di
   M6 ini) → `error.not_found` 404 dari `latest_template_version`/service,
   bukan sukses kosong.
7. **Tes integrasi vs transaksi aborted PG** — `pytest.raises` diletakkan DI
   LUAR `tenant_scope` untuk kasus yang gagal di statement DB (trigger,
   duplikat unique): exception harus menembus blok `atomic` agar Django
   rollback ke savepoint; jika ditangkap di dalam, RELEASE savepoint pada
   transaksi yang sudah aborted malah melempar error kedua (analogi pola
   `test_rls.py::test_composite_fk_rejects_cross_tenant_reference`).
8. **Pembersihan artifact tes** — fixture `doc_paths` menghapus file yang
   dibuat tes: MT_STORAGE_ROOT dev (.env) menunjuk root penyimpanan bersama
   di clone utama; tes tidak boleh meninggalkan sampah di sana (diverifikasi:
   0 file tersisa setelah run).
